# Social App (Expo + React Native)

    npm install
    npx expo install --fix   # aligns package versions with your Expo SDK
    npx expo start

Screens live in `src/app` (Expo Router):
- `(unauthenticated)/login.tsx`, `register.tsx`
- `(authenticated)/(tabs)/home.tsx`, `profile.tsx`

Placeholder images: `assets/images (2..5).png` (wired in `src/data/mock.ts`). Colors: `src/theme/colors.ts`.
